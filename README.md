# ZMUM-Telco-Customer-Churn
## 🇬🇧 English
An analysis and classification project focused on predicting customer churn for a telecommunications company using Python and the "Telco Customer Churn" dataset. It features a comprehensive preprocessing pipeline, including four data imputation strategies and manual implementations of feature scaling to evaluate their impact on model performance.
## 🇵🇱 Polski
Zaawansowany projekt uczenia maszynowego dedykowany predykcji odejść klientów (churn) w branży telekomunikacyjnej. Serce projektu stanowi rozbudowany potok przetwarzania danych, obejmujący cztery strategie imputacji oraz ręczną implementację skalowania cech w celu analizy ich wpływu na skuteczność klasyfikacji.
